# Komponen Pihak Ketiga

Aplikasi ini memakai dan menyertakan komponen berikut. Masing-masing tetap tunduk pada lisensinya sendiri; lisensi MIT proyek ini (`LICENSE`) tidak menggantikannya.

## Ikut di repositori / aplikasi web

| Komponen | Versi | Lisensi | Lokasi |
|---|---|---|---|
| CodeIgniter 4 | 4.7.5 | MIT | `vendor/codeigniter4/framework`, `license.txt` |
| Dompdf | 3.1 | LGPL-2.1 | `vendor/dompdf/dompdf` |
| php-font-lib | 1.0 | LGPL-2.1-or-later | `vendor/dompdf/php-font-lib` |
| php-svg-lib | 1.0 | LGPL-3.0-or-later | `vendor/dompdf/php-svg-lib` |
| PHP CSS Parser (sabberworm) | 9.5 | MIT | `vendor/sabberworm/php-css-parser` |
| masterminds/html5 | 2.11 | MIT | `vendor/masterminds/html5` |
| laminas-escaper | 2.18 | BSD-3-Clause | `vendor/laminas/laminas-escaper` |
| psr/log | 3.0 | MIT | `vendor/psr/log` |
| Chart.js | 4.4.1 | MIT | `public/vendor/chartjs/` (lisensi: `LICENSE.md`) |
| Lucide icons | 0.460.0 | ISC | jalur SVG di `app/Helpers/ikon_helper.php` |
| DM Sans | – | SIL Open Font License 1.1 | `public/fonts/` (`LICENSE-dm-sans.txt`) |
| Source Sans 3 | – | SIL Open Font License 1.1 | `public/fonts/` (`LICENSE-source-sans-3.txt`) |

Pustaka LGPL (Dompdf dan turunannya) dipakai tanpa diubah dan dimuat lewat Composer, sehingga pengguna tetap bebas mengganti versinya sesuai ketentuan LGPL.

## Merek dagang

Nama dan logo perusahaan yang diatur di halaman **Identitas Perusahaan** adalah milik perusahaan pemakai masing-masing dan **tidak** termasuk dalam lisensi MIT. Repositori ini tidak menyertakan logo perusahaan mana pun; ikon bawaan `public/img/app-icon.png` dibuat untuk proyek ini dan berlisensi MIT.
